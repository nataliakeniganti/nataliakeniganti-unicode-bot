Unicode Bot

A small Discord bot to insert or transform unicode characters — this repository contains the bot code and a simple GitHub Pages site.

About

This project provides a Discord bot that helps with unicode characters and fancy text formatting for messages. Use the bot in your server to paste, transform, or look up unicode characters.

Invite the bot

Replace YOUR_CLIENT_ID with your application (client) ID and open the following URL to invite the bot to a server:

https://discord.com/oauth2/authorize?client_id=YOUR_CLIENT_ID&scope=bot+applications.commands&permissions=0

If you want, you can replace YOUR_CLIENT_ID with your app ID. For security, never share your bot token.

Usage examples

Example commands (adjust to your bot's prefix):

!unicode ♡
!fancy hello
!lookup ☺

Application URLs

The following application URLs are useful when configuring your bot in the Discord Developer Portal. They are optional and can be set in the "OAuth2" / "General Information" / "Interactions" sections of your application.

  • Interaction endpoint (POST): https://nice-example.local/api/interactions
  • Linked role verification URL: https://nice-example.local/verify-user
  • Terms of Service: https://my-cool-app.com/terms-of-service
  • Privacy Policy: https://my-cool-app.com/privacy-policy

If these are local or development URLs (like https://nice-example.local) make sure they are reachable from Discord's servers or use a public HTTPS endpoint (or a tunneling service) for interactions to work.
